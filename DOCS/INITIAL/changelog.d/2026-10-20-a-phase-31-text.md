### Phase 31 (Text on the canvas)

You type directly on the canvas.

#### Added
- Draw a text box with the Text tool and type into it at once; double-click a text layer, or press Enter on it, to edit it in place. Cmd/Ctrl+B, I, U and Shift+X style the selected words; Enter is a new line; paste is always plain text; Escape (or Cmd/Ctrl+Enter, or clicking away) leaves, as one undo step. Leaving a text box empty discards it.
- Styled runs inside one text layer (`content.runs`), saved with the document and shown on the canvas and in the stage.
- Text sizing: auto width (a click with the Text tool), auto height, fixed (`text.sizing`).
- Text properties in the inspector: family, size, weight, line height, letter spacing, alignment, decoration, case, and the sizing mode. A value the selection disagrees on reads "Mixed".
- Typed commands for agents and controls: `layer.setProps`, `text.setSizing`, `text.set`, `text.edit`.
- `src/core/text/runs.ts` (pure), `textStyle.ts` (the typography CSS the renderer and the editor share), tests in Chromium, Firefox and WebKit, and an IME composition test in Chromium.

#### Changed
- Text layers now draw their line height, letter spacing, decoration, case and italic (before, only size, weight, family, colour and alignment).
- An empty text layer renders empty instead of showing its layer name.
- Enter on a selected text layer edits it (other layers still select their children).
