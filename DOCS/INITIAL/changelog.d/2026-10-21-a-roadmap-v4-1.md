### Roadmap v4.1: Design depth, Characters & rigging, and 75 new phases

The roadmap grows from 202 to 277 phases so the finished editor covers everything React Bits shows and more. A check of all 218 React Bits components against the roadmap found 161 already covered and 57 that needed something new. Phases 1–102 keep their numbers. Every phase from 103 on is renumbered; the old-to-new table is at the end of ROADMAP §7.

#### Added
- **Stage 3 · Design depth (103–131, new; proposed for Lane A after Phase 52):**
  - live boolean groups that keep curves as curves, a Shape Builder, offset, outline and knife, smooth corners, gooey groups;
  - a non-destructive modifier stack (repeat, trim, twist, wiggle …) and shape generators (scatter, Voronoi, flow lines);
  - a blend mode and a mask on every fill, plus noise, pattern, mesh and live fills, on shapes and on text;
  - several strokes, variable-width strokes and pressure brushes;
  - glow, progressive blur and frosted glass, image adjustments, colour tools, and an icon and stock media panel;
  - text on a path and inside shapes;
  - 2.5D spaces with depth, 3D arrangements and a depth camera.
- **Stage 4 · Interactive (was Stage 3), 26 new phases:**
  - every layer's live self (speed, scroll progress, distance to the cursor);
  - microphone, camera, gamepad and tilt inputs;
  - drag a property onto any input to connect them;
  - velocity effects, and layout reactions inside fixed boxes (variable-font proximity, Dock magnification);
  - gestures, constrained dragging, carousels and seamless loops, drag and drop;
  - roles and selectors ("every button"), and data-driven charts;
  - joints, ropes and soft bodies, sound and haptics;
  - a scene rasteriser, layer textures, outlines and distance fields;
  - effect layers, outline effects, liquid glass and 2D lights;
  - deformation and fracture, scroll-scrubbed sequences, smooth scrolling and depth parallax;
  - another library wave.
- **Stage 5 · Characters & rigging (203–217, new):** Rive-style bones, posing on the timeline, mesh weights, IK, constraints and jiggle, puppet pins, rigs that react to the cursor and keys, state blends, auto-rig, faces and lip sync, webcam face tracking, a `rig` export runtime and a library.
- **Stage 6 · 3D (was Stage 4):** inflate any vector into 3D, 3D skeletons and IK, and real page layers inside 3D scenes.
- **Stage 7 · AI (was 5):** an AI character animator. **Stage 8 · Easy for everyone (was 6):** recipes that replay how anything was made.
- Decision records 0015 (path engine), 0016 (scene rasteriser) and 0017 (rigging) are claimed in `DOCS/TEAM/CLAIMS.md`.
- `DOCS/INITIAL/REACT_BITS_COVERAGE.md` maps each React Bits component to the phases that let a user build it. It records ideas only; no React Bits code is copied.

#### Changed
- Phase 139 (was 108) has a carve-out so continuous reactions may change layout inside a layout-isolated box.
- Phases 177, 183, 187, 191, 197, 201 and 202 (were 132, 134, 136, 137, 142, 146 and 147) build on the new layer textures, roles and outlines. Phase 240 (was 167) is the Stage 6 gate and has a new journey.
- Decision records 0008 and 0009 and AUD-51 use the new numbers. `DOCS/TEAM/COLLABORATION.md` §1 records the Stage 3 proposal.
- `LICENSES.md`: the React Bits BranchedMenu in the editor's own interface is a recorded exception to GATE-02. `polygon-clipping`, `@hugeicons/*` and `fflate` (all MIT) are recorded.
