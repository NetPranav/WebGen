### FigCraft port (Figma depth in our engine)

FigCraft's engine logic (MIT) is being translated into ours, batch by batch, under `DOCS/INITIAL/FIGCRAFT_PORT_PLAN.md`. Only data and behaviour are taken; our canvas and exports still draw everything as DOM, SVG and CSS. The licence is recorded in `LICENSES.md` and `THIRD_PARTY_NOTICES.md`.

#### Added
- **F1 shape geometry:** rectangles honour each corner's own radius and a new corner smoothing (the continuous-curvature corner, `shape.cornerSmoothing`); polygons and stars draw their rounded vertices (`shape.vertexRadius`, stored since Phase 7 but never drawn) with smoothing; ellipses become arcs, pies and rings (`shape.arcStart`, `shape.arcSweep`, `shape.arcInnerRatio`). `src/core/geometry/bezpath.ts` (the curve core), `shapes.ts`, `affine.ts`.
- **F2 colour and paint:** `src/core/paint/color.ts` (hex shorthands, every CSS colour name, HSB/HSL, WCAG contrast, Display P3 conversion and `color(display-p3 …)` text, gradient sampling, pattern cells, image crop maths). Fills gain a blend mode each, a diamond gradient (drawn exactly as four quadrant gradients) and the seven image adjustments with presets (drawn by an SVG colour filter).
- **F3 strokes:** several strokes per shape (`paint.strokes`, any paint), stroke position inside / centre / outside (`stroke.align`; frames use a border or an outline), per-side weights (`stroke.sides`), variable width profiles with presets (`stroke.widthProfile`), arrowheads and round, square, circle and diamond ends on lines and pen paths (`shape.startCap`/`endCap`), and the miter limit. `src/core/geometry/measure.ts`, `src/core/paths/pathOps.ts` (booleans with fill rules, arrangement faces), `src/core/paths/strokes.ts`, `src/core/render/strokePaint.tsx`. Commands `paint.setStrokes` and `stroke.set`; a Stroke settings block in the Pro inspector.
- **F4 vector networks:** points joined by any number of curves, filled by regions (`src/core/paths/vectorNetwork.ts`, stored on path layers as `svg.network`), points with their own corner radius, handle mirroring, cap and join, and the Paint Bucket tool (B) that fills or unfills any closed area. Commands `vector.makeNetwork`, `vector.paintBucket`, `vector.setPoint`; a "Make vector network" button.
- **F5 booleans and the Shape Builder:** live boolean groups whose operands stay editable layers (`boolean.operation` on a frame, `boolean.operandOp` per operand; commands `boolean.makeGroup`, `boolean.setOperation`, `boolean.flattenGroup`), and the Shape Builder tool (Shift+M) that merges, or with Alt removes, the regions where selected shapes overlap (`shapeBuilder.regions`, `shapeBuilder.merge`, `shapeBuilder.remove`).
- **F6 auto layout:** auto gaps Space around and Space evenly, Baseline alignment, wrapped lines packed where the cross alignment says or spread (`layout.alignContent`), inside strokes in or out of the layout (`layout.strokesIncluded`), first child on top (`layout.reverseZ`), a grid child's place in its cell (`layout.justifySelf`), Fill on a child fixing a hugging parent, arrow keys moving a child through its stack, and layout grids (columns, rows, square grid) drawn over frames (`frame.layoutGrids`, a Layout grids panel, `layout.setLayoutGrids`).
- **F9 components:** Push changes to main, Combine as variants, duplicating a main component makes an instance of it, component descriptions (`designComponents[].description`), the top-left variant as the default for new instances, and layers inside an instance keep the main's place, rotation and constraints (their look and size can still change). Commands `component.pushChanges`, `component.combineAsVariants`, `component.setDescription`; buttons and a description box in the Component panel.
- **F10 variables and styles:** variable collections, each with its own modes (add, duplicate, reorder — the first is the default — rename, remove); string and boolean variables (text, font family, visibility); aliases (a value that is another variable, cycles refused); scopes (which properties the picker offers a variable for); descriptions and code syntax per platform; a frame choosing a collection's mode for everything inside it, which instances take from their main; paint styles (fill or stroke) and grid styles beside text and effect styles; variables bound inside styles, resolved in each layer's modes. New `token.*` commands for collections, modes, aliases and frame modes; the Tokens tab and the inspector's bindings panel show them.
- **F7 effects:** an effect list per layer (`paint.effects`, command `paint.setEffects`, edited in the Pro inspector): layer and background blurs that can be progressive (the radius ramps between two points), noise grains (mono, duo or every colour, with density, size and blend), texture (roughened edges) and glass (an approximation: frosted backdrop with highlights from the light's angle). Drawn the same on the canvas and in the export.
- **F8 text:** bulleted and numbered lists nested up to eight levels (1. a. i. and • ◦ ▪, a list can start at any number, Tab-style indent and outdent), paragraph spacing and first-line indent, list spacing, hanging lists and punctuation, a maximum number of lines before an ellipsis, top/middle/bottom placement in a fixed box, cap-height trim, decoration style (dotted, wavy), thickness, offset and ink skipping, small caps, OpenType feature toggles, and text on a path (put the text on any shape, choose where it starts and which side). Commands `text.setList`, `text.indentList`, `text.setListStart`, `text.attachToPath`, `text.setPath`, `text.detachFromPath`.
- **F12 editing:** Alt-drag copies the selection (and Duplicate repeats that step), the Scale tool (K) scales everything in a layer by one factor about an anchor (strokes, radii, effects, spacing, text), a movable rotation origin (Alt+R), Alt-hover measuring from the selection to another layer, arc handles on ellipses, and a Selection block in the Pro inspector: the selection's colours (change one everywhere, or select the layers using it), the gaps between its rows and columns, and batch rename with find and replace and `$n` numbering.
- **F11 frames and export:** resize a frame to fit its layers, convert a frame to a group (its box becomes its layers', what only a frame has goes) or to a section (a canvas organiser that shows its name) and back, and per-layer export settings (PNG, JPG or SVG at a scale with a suffix) that save the layer as files drawn exactly as on the canvas.
- **F13 Dev Mode:** the Code tab's Inspect view: a layer's properties for handoff with the styles and variables behind them (colours in hex, RGB, CSS, HSL or HSB; px or rem) and its CSS, where a property bound to a variable uses the variable's code syntax (`var(--space-xs, 4px)`); annotations with pinned properties and categories; measurements kept on the canvas; ready-for-development status with Compare changes.
- Paint editor: a blend menu per fill, Diamond in the type list, adjustment presets and sliders for image fills.
- Render gallery cases for every new shape and paint.

#### Fixed
- The HTML export added line breaks between text and the elements mixed with it, which showed in text that keeps its white space (styled runs, list markers).
- Eight canvas-lab browser specs could click a lab button before React hydrated; the click was lost and the test timed out under load. They now wait for hydration.
- The image adjustment fields reused the names of the brightness/contrast/saturation fields (found by the Phase 37 browser tests).
- `paint.setFills` rejected the diamond gradient and dropped blend modes and image adjustments, so those F2 controls couldn't save.

#### Not done
- Nested components and the instance-swap property (components still don't nest).
- Variable bindings by paint-list index on layers, style folders, and variables import/export (F10 leftovers).
- Shadow blend modes and "show behind transparent areas" (CSS shadows have neither); true glass refraction (left to the GPU compositor).
- Per-run font size, family and fills (our runs carry bold, italic, underline, strike and colour).
- From F12: the Scale tool's live readout, drag-to-reorder of a smart selection on the canvas, measuring padding and gaps with Shift+Alt.
- From F11: slices, PDF export and SVG export options; frames inside a section don't count as pages.
- From F13: annotation pins on the canvas, comparing with a saved version.
- The rest of the plan ( text, editing behaviours, Dev Mode, import): see the plan's status column.
- Pattern fills: the cell maths is ported, but drawing a layer as a repeating tile needs a renderer change (CSS has no portable `element()`).
